# 합성 행사 재배치 시연

실제 고객 정보 없이 독립 실행하는 예제다. 상담20건·통역사4명·공간5개와 변경 장면4개를 사용한다. Node24.x 이외 설치 의존성·API 키·외부 요청·DB가 없다.

저장소 루트에서:

```powershell
node --test --test-concurrency=1 examples/scheduling-simulation/engine.test.cjs
node examples/scheduling-simulation/start.mjs
```

출력된 `127.0.0.1` 주소를 연다. 종료는 Ctrl+C다. HTML 파일이 필요하면 `node examples/scheduling-simulation/build.mjs`를 실행하고 생성된 `dist/index.html`을 브라우저로 연다. 생성 파일은 Git에서 제외한다.

| 장면 | 직접 영향 | 변경 후보 | 미배정 |
| --- | ---: | ---: | ---: |
| SC01 통역사 지각 | 1 | 1 | 0 |
| SC02 공간 불가 | 5 | 5 | 0 |
| SC03 바이어 시간 변경 | 1 | 1 | 0 |
| SC04 통역사2명 부재 | 10 | 1 | 9 |

화면은 선택 → 계산 → 변경 검토 → 취소/가상 반영 흐름을 제공한다. 미배정이 있으면 반영할 수 없다. 다른 장면 선택은 기본 배치에서 다시 시작하며 새로고침하면 가상 기록이 사라진다.

`engine.cjs`는 기존 유효 배치를 고정한 순차 탐색이다. 10분 단위 후보의 언어·가용시간·중복·통역사 간격을 검사한다. 전역 최적해나 일반적 불가능 판정, 전체 출원 기술 구현을 증명하지 않는다. SC04의 미배정9건은 언어 부재5건과 제한 탐색에서 후보를 찾지 못한4건이다.

기본 배치·4장면·제약 오류·미지원 장면·공개 HTML 구성의8개 시험을 제공한다. 이전 비공개 자금 모델 시험은 포함하지 않는다. 공개 예제는 고객명·실제 원본·사업계획서·견적·자금계획을 포함하지 않는다.

서버 저장·계정·동시 수정·정산·백업·실제 실증은 미구현이다. VenturePass 제품75%를 올리거나 실제 계약·납품·승인·기관 완료로 표시하지 않는다.
