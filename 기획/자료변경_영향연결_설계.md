# 21. 자료 변경 영향과 재검토 연결

상태: 구현·범위 회귀 37개·독립 검토·전체 회귀·격리 배포 화면 검증 완료. R06의 기존 자료 참조를 읽어 계산하며 별도 이력 DB나 의미 검색을 추가하지 않는다.

## 연결 범위

자료 ID에서 현재 분석의 후보·기재 내용, 선택 당시 후보, 원고 항목, 사전진단, 검토 의견 처리, 주장 검토, 소명, 보완 답변, 실사 답변, 수치 대조, 기관 원본, 제출 당시 근거로 연결한다. 주장에 명시한 수치/검토 기록의 정확한 ID·버전도 경유 관계로 표시한다. 해당 보조 기록의 입력 digest·기록 시각·저장 연결이 다르면 자료 ID를 추정하지 않고 정보 부족으로 남긴다.

원고 항목 인용만으로 특정 문장이 영향받는다고 추정하거나 다른 원고를 통한 의미 관계를 만들지 않는다. 과거 제출본과 이전 검토 버전은 역사적 연결로 표시하고 저장 데이터를 변경하지 않는다.

## 상태와 한도

- 변경 확인: 저장 시각·메타정보·정확한 인용과 현재 등록 자료가 다르다.
- 정보 부족: 버전이 없는 구형 인용, 중복 ID, 누락되거나 충돌한 스냅샷, 미지정 보조 연결이다. 인용만 같다고 최신 근거로 표시하지 않는다.
- 등록 버전·인용 일치: 해당 등록정보와 인용 대조만 일치한다. 현재 원본 바이트나 전체 본문 SHA 검증·사실 확인 결과가 아니다.

자료 하나의 연결 상태와 산출물 전체의 재검토 상태를 구분한다. 전체 산출물의 다른 근거가 바뀐 것을 현재 자료 탓으로 표시하지 않는다. 연결 2,000개 표시 한도에 도달하면 잘림을 알리며, 인용·대상 일부는 300자로 표시하되 정확 인용 대조는 전체 값으로 한다. 연결이 없다는 사실을 영향 없음으로 간주하지 않는다.

## 화면 이동

자료함의 영향 목록에서 자료·상태를 필터링하고 정확한 연결 대상으로 이동한다. 이동 직전 회사 ID·revision·현재 연결 목록의 정확한 대상이 일치하는지 검사한다. 원고와 주장은 당시 원고 버전·고유 항목을 열고, 과거 주장 상세도 해당 기록으로 펼친다. 원고를 찾지 못하면 최신 원고로 대체하지 않는다. 다른 종류는 해당 탭에서 대상 ID와 버전을 표시한다. 기존 편집·진행 작업 보호를 유지한다.

## 검증

구형 자료, 회사·버전·인용 차이, 중복 ID와 스냅샷, 보조 기록 누락·변경, 원고를 통한 임의 관계 배제, 과거 제출/판단 보존, 한도·표시 잘림, 이동 대상 검증과 UI escaping을 합성 검사한다. 실제 화면에서는 자료 변경→과거 주장→정확한 원고 버전 이동과 새 검토 버전 저장을 확인한다. 실제 기관 또는 외부 AI 실행은 없다.
