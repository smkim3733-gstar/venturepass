## 후속 통합 작업의 완료 기준

- 별도 저장 후 fixture에서 시작하는 대신 한 화면 세션에서 합성 답변 저장부터 최신 원고/검토/Word까지 이어간다.

- 검토 판단은 기존 의견/확인 필요를 해제하지 않고, 내려받기는 실제 화면에서 선택한 저장 버전을 사용한다.

- 실제 고객 자료, 기관 제출, 새 외부 호출, 유료 AI, SQL writer의 승인으로 해석하지 않는다.
