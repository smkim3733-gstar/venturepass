# 과거 제출본과 현재 원고·신청번호 연결 점검 — 2026-10-09 / 4G9

4G8 이후 지정받은 한 작업을 완료했다. 변경된 현재 원고를 과거 신청의 제출본으로 대신 표시하는 구체적인 연결은 이번 점검 범위에서 발견하지 못했다. 기존 구현과 합성 시험 코드가 해당 구분을 이미 다루므로 제품·시험 코드를 바꾸거나 완료 검증을 반복하지 않았다. 모든 데이터 조작은 소스 읽기이며 고객 앱/DB나 기관 화면을 새로 열지 않았다.

기존 integration 시험에는 회사정보/담당자를 바꿔도 고정 제출 기록이 동일한지, 새 초안 작성 뒤 과거 원고로 수동 기록하고 정정해도 이전 기록이 남는지의 단언이 있다. 표시 시험에는 당시 원고·검토·담당자와 기관 미확인 표시, 원본 해시와 현재 파일의 구분이 있다. 후속 안내 시험은 서로 다른 고정/현재 원문 버전과 수동 귀속 이전·해제를 다룬다. 이번에는 시험 코드를 읽었으며 실행하지 않았다. 과거 시험의 존재를 이번 통과나 실제 고객 흐름 검증으로 세지 않는다.

이는 지정된 버전 연결 범위의 소스 점검 결과다. 전체 앱의 무결함 보증이나 실제 기관에서 어느 원고를 받았는지 확인한 결과가 아니다. reported-submitted/manual-unverified와 공식 접수·심사 결과를 계속 구분한다.

## 실제 기관 근거가 필요한 남은 경계

- F18: 현재 제출용 화면의 최종 검토·확인·제출 동작, 동일 신청 중복 접수 방지와 결과 불명 후 복구. 읽기 전용 과거 신청서로 이 동작을 확정할 수 없다.
- F19: 실제 접수 확인에 표시되는 신청 식별자와 원래 실행/선택 회차의 일치, 접수 문서의 출처와 보관. 수동 접수 통보 연결만으로 공식 접수증이 되지 않는다.
- F20: 공식 결과/확인서 표시와 정확한 회사·신청 건의 귀속, 그 출처를 보존하는 읽기. 사용자의 “확인 완료 업체” 설명은 회사 맥락이며 특정 화면/번호의 자동 귀속 근거를 대신하지 않는다.

기존 4G7 신청서내역 7탭에는 신청번호/접수번호/신청유형의 명시 라벨이 없었다. 다른 배경 행과 날짜만으로 상세를 귀속시키지 않았다. 이를 해결하기 위해 현재 확인 완료 업체에 신규 신청이나 작성중 화면을 요구하지 않는다. F12/F13의 미완료 범위도 그대로이며 이번 작업을 통계 재로그인/호출이나 유료 AI 반복으로 전환하지 않는다.

## 다음 읽기 범위 — 아직 실행하지 않음

결정은 하나다. 현재 확인 완료 업체의 **기존 신청 1건의 결과·확인서 관련 화면을 저장 없이 읽는 단계**로 진행할지다. 이번 작업의 “새 실제 고객 조회/저장 없이 소스와 합성 자료로 대조” 범위를 넘는 새 기관 화면 읽기이므로 그 한 가지를 확인한다. 이미 승인한 합성 앱 개발이나 과거 완료 조회를 다시 승인받는 질문이 아니다.

승인 시의 구체적 범위:

1. 사용자가 열어 둔 기존 벤처인 MY에서 현재 회사/선택한 완료 신청이 명확한지 확인한다. 임의로 첫 행이나 다른 회사를 고르지 않는다.
2. 그 1건에 실제 표시된 결과와 확인서 관련 화면까지만 읽는다. 대상 화면 열기/이동은 합계 최대3회, 반복·자동 재시도0이다. 이는 브라우저 조작 상한이며 페이지 내부 네트워크 GET 횟수 보증이 아니다.
3. 화면 항목명, 회사·신청 식별자의 표시 여부, 같은 건으로 대조 가능한지, 상태/발급·유효기간 표시 구조만 개발 근거로 정리한다. 실제 고객 값/신청번호/원문·전체 URL·SSO·쿠키·스크린샷·파일은 문서/Git/로그에 보관하지 않는다. 필요한 일치 대조만 메모리에서 한다.
4. 파일보기/다운로드/인쇄·입력/첨부/저장/신규·재신청/동의/최종제출/납부/서명은 실행하지 않는다. 고객 앱 DB에도 쓰지 않는다.
5. 로그인 종료, 대상 귀속 불명, 새 신청·쓰기 요구, 해당 표시 부재이면 그 상태를 기록하고 중단한다. 보이지 않는 절차/버튼/API를 추정하지 않는다.
6. 수동 원장/번호 연결을 재사용할 수 있는 실제 읽기 근거가 확보되면 필요한 최소 연결을 판단한다. 실제 최종제출 실행 성공, F19/F20 전체 완료로 집계하지 않는다.

승인 후 제한 읽기와 연결 판단은1~3시간(잠정), 구현이 필요한지·실제 제출 검증/전체 완료시간은 현재 미정이다. 지금 로그인이나 새 신청을 요구하지 않는다.
