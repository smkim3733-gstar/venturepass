# 자료 업로드 확인 안내

현재 PC의 VenturePass에서 자료가 보관됐는지 확인하는 방법입니다.

1. 회사 작업공간의 **자료 올리기**에서 PDF·워드 파일을 선택합니다. 워드는 DOCX를 지원합니다. DOC 파일은 워드에서 DOCX 또는 PDF로 다시 저장해 주세요. 파일당 12MB이며, 회사별 파일 수 한도는 현재 화면의 안내를 확인해 주세요.
2. **이번에 선택한 자료**에서 각 파일의 결과를 확인합니다. 저장 중인 파일, 저장 완료, 저장 실패, 저장 여부 확인 필요, 전송하지 않은 파일을 구분합니다. 중간 파일에서 실패하면 뒤의 파일은 전송하지 않습니다.
3. **저장된 자료 N개**는 서버가 보관한 목록입니다. 새로고침하거나 회사를 다시 열어도 확인할 수 있습니다. **원본 내려받기**로 파일을 직접 대조하고 **본문 확인·고치기**로 읽은 내용을 확인합니다.
4. **원본 보관 · 본문 확인 필요**는 파일 보관은 끝났지만 글자를 읽지 못했다는 뜻입니다. 스캔 PDF는 이 상태로 보관되며, 자동으로 외부 AI에 전송하지 않습니다. 본문 확인 화면에서 직접 입력하거나 제공되는 로컬 글자 읽기를 선택할 수 있습니다.
5. **저장 여부 확인 필요**가 나오면 같은 파일을 다시 보내기 전에 **저장 상태 확인**을 누릅니다. 목록과 원본을 대조하세요. 불명확한 전송은 자동으로 재시도하지 않습니다.
6. 파일과 본문을 확인한 뒤 **자료 확인 후 다음 단계**로 이동합니다. 파일 업로드 성공이 사실 확인이나 AI 분석 완료를 뜻하지는 않습니다.

이번 선택의 파일별 결과는 현재 화면에서 보여 줍니다. 새로고침 후에는 저장된 자료 목록을 기준으로 확인합니다. 실패·전송하지 않은 파일은 저장된 자료에 포함되지 않습니다.

## 첨부파일 카드로 확인하기

- 선택 직후 파일명·PDF/WORD 등 형식 아이콘·크기·전송/저장 상태가 카드에 표시됩니다. 아이콘은 파일 형식 표시이며 실제 문서 첫 페이지 미리보기는 아닙니다.
- 위쪽 **저장된 자료** 카드에서 읽힌 본문 일부와 등록 시각을 볼 수 있습니다. 파일명 또는 **본문 확인·고치기**를 누르면 상세 내용을 확인합니다.
- **파일명이나 본문으로 찾기**로 검색하거나 **본문 확인 필요**만 골라볼 수 있습니다. 처음에는 최근 자료12개를 표시하며 **자료 더 보기**로 나머지를 펼칩니다.
- 검색과 필터는 화면 목록만 바꿉니다. 검색 결과만 AI에 전달되는 것은 아니며, AI 전송 전에는 별도 확인 화면을 확인하세요.
- 현재 화면의 저장 카드가 기준입니다. 시험용16개 저장 검증은 사용자가 올린 실제16개가 저장됐다는 의미가 아닙니다.

50~200개 자료를 안정적으로 보관하고 원고의 근거로 쓰는 후속 방향은 [대량 자료 처리 분석](./자료보관함_대량자료_품질개선_20261003.md)에 정리했습니다. 카드 검색 개선과200개 처리 지원은 별개입니다.

## 파일을 끌어다 놓아 올리기

1. 진행 중인 업로드가 끝났다면 앱을 새로고침합니다. 회사의 **자료 올리기** 화면 위쪽에 점선 영역이 있습니다.
2. Windows 파일 탐색기에서 파일 여러 개를 선택하고 **파일을 이곳에 끌어다 놓으세요** 영역으로 가져옵니다.
3. 영역이 강조되면 마우스를 놓습니다. 추가 버튼 없이 업로드가 시작되고 파일별 카드에 저장 상태가 나타납니다.
4. 폴더 자체는 올리지 않습니다. 폴더를 열고 안의 파일들을 선택해 놓아 주세요. 폴더가 섞인 묶음은 전송하지 않고 안내합니다.
5. 저장 중이거나 저장 여부 확인이 남은 동안에는 추가 드롭을 받지 않습니다. 기존 저장·확인이 끝난 뒤 다음 파일을 올립니다.

기존 **자료 올리기** 버튼도 계속 사용할 수 있습니다. 점선 영역 밖에 놓은 파일은 업로드하지 않으며 앱 화면을 파일 뷰어로 바꾸지 않습니다. 끌어놓기도 기존 파일 크기·자료 수·형식 검사와 실패/불확실 상태 표시를 사용합니다. 이 동작으로 외부 AI에 자료를 전송하지 않습니다.
