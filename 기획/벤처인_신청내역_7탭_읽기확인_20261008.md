# 벤처인 신청내역 7개 탭 읽기 확인 — 2026-10-08 / 4G7

사용자 정정(2026-10-08): 현재 연결 기업은 이미 혁신성장유형 벤처확인을 받은 업체다. 사용자가 앞서 알린 이 맥락을 놓치고 작성 중/임시저장 신청서를 개발의 필수 조건으로 요청한 판단을 철회한다. 이번 기업은 기존 신청서의 항목 구성과 완료 후 결과 표시를 확인하는 참고 사례다. 새 신청/재신청·작성 화면 제공을 이 기업에 요구하지 않는다. 회사의 확인 완료 사실만으로 지금 열린 특정 과거 상세와 신청번호의 귀속이나 벤처패스 자동 접수 성공을 확정하지 않는다.

사용자가 기존 기업의 신청내역 상세를 직접 열고 “열었어”라고 알렸다. 기존 무입력 읽기 승인으로 현재 열린 창을 확인했다. 이전 4G6의 ‘신청내역 상세가 열리지 않아 구조를 볼 수 없음’은 해소됐다.

## 확인한 화면과 한계

공식 경로는 https://www.smes.go.kr/venturein/myVntr/viewMyVntr 이며 같은 문서 안에 ‘신청서내역’ 레이어가 열려 있었다. 이번에는 7개 탭을 각각 확인했다. 사용자 창을 닫지 않았고 마지막에 원래 ‘신청서’ 탭으로 돌려놓았다. 페이지 네트워크 요청 횟수는 계측하지 않았다.

기술 설명에 ‘신기술(제품) 인증을 위한 노력’, ‘기술 소개 및 필요성’, ‘기술 개발 과정의 구체화’, ‘기술의 현실화’, ‘기술의 발전 계획’, ‘기술의 파급 및 기대효과’가 보였다. 사업성장성에는 마케팅·브랜딩·네트워킹·조직관리·글로벌 확산·투자(유치)/자금조달 계획과 이익공유·일가정친화·환경친화·기타가 보였다. 이를 현재 접수 양식의 확정 항목이나 필수 기준으로 승격하지 않는다.

첨부 구분에는 사업자등록증, 부가가치세과세표준증명원, 재무제표/감사보고서, 고용보험 사업장 취득자 명부, 4대 사회보험 사업장 가입자 명부, 대표자 학력·경력·기술자격 증빙, 연구개발조직 인정서가 표시됐다. 이는 이 기존 기록에 표시된 분류이며 모든 신청의 필수서류 목록이 아니다. 파일명·내용은 보관하지 않았고 파일보기/다운로드/인쇄를 실행하지 않았다.

레이어 전체 DOM에서 비숨김 input0, select0, file input0, textarea21개 모두 readonly였다. 기술혁신성은 표시 표였고 사업성장성에는 읽기 전용 textarea가 있었다. 모든 탭에 편집/저장/최종 제출 기능은 관측되지 않았다. 읽기 전용 textarea의 maxlength 부재를 실제 입력 한도 없음으로 해석하지 않는다.

레이어 안에는 신청번호/접수번호/신청유형의 명시 라벨이 없었다. 배경 MY의 다른 행이나 날짜만으로 상세의 신청번호·현재 회차를 자동 귀속하지 않았다. 동적 레이어 ID도 고정 선택자로 제품에 넣지 않았다. 현재 열린 기록이 최신 작성 양식과 동일하다고 확인한 것은 아니다.
