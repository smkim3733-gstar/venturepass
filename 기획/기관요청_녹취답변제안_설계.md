# 기관 요청·녹취의 미검토 답변 제안

상태: R08의 읽기 전용 서버/API와 기존 편집기 연결, 범위 검사·독립 검토·고정 전체 검사·격리 API/UI 검증을 완료했다. 기존 보완 답변 준비와 실사 답변 편집을 재사용한다. 새로운 발송·심사 판정·사실 확인 기능이 아니다.

## 대상과 결과

1. 보완 요청의 정확한 최신 버전과 원문 범위를 고정해 요청 요약, 관련 자료의 정확한 인용 후보, 부족 자료 질문을 제안한다. 선택한 제안은 기존 답변 준비 편집기에 미검토 초안으로 채우고 별도 저장한다.
2. 실사 질문의 정확한 원고·질문 버전과 사용자가 선택한 채택된 녹취 자료를 고정한다. 해당 질문과 관련된 원문 답변 구간을 제안하고 선택한 구간만 기존 모의 답변 편집기에 연결한다. 파일 전체나 이전 질문의 답변을 자동 덮어쓰지 않는다.

## 근거와 표시

- 로컬 보조는 명시 원문 발췌·단어 일치 후보를 제공한다. 단어 일치가 의미의 적합성이나 사실 일치임을 주장하지 않는다. 결과가 없으면 부족/미확인으로 남긴다.
- 외부 AI 보조 경로는 요청/질문 및 선택 자료 본문과 전송 대상·모델·목적을 표시하고 사용자가 명시 허용한 경우에만 실행할 수 있다. 개발 단계에서는 모의 공급자로 계약을 검사하고 실제 사용자 자료를 보내지 않는다.
- 결과에는 rule/model 식별, 회사 revision, 요청/질문/자료의 ID·수정시각·내용 해시, UTF-16 인용 범위와 정확한 원문을 둔다. 저장된 실제 페이지/셀/자막 좌표가 현재 본문 해시와 일치할 때만 위치를 함께 제시한다. 교정 후 일치하지 않는 좌표나 음성에 없는 시각을 만들어 넣지 않는다.
- 미채택 판독 결과와 pending 자료는 확정 근거 후보로 사용하지 않는다. 사용자가 교정·채택한 전사 본문도 진위 확인된 사실과 구분한다. 연락처·자격정보·다른 회사·미선택 자료는 입력에서 제외한다.
- AI 출력의 source ID·원문 범위·인용·요청/질문 버전은 서버가 재검사한다. 없는 인용·잘못된 범위·출처 없는 단정은 저장하지 않는다. 원문 안의 지시문은 처리 지시가 아니다.
- 편집기로 가져올 때 미검토 상태로만 채운다. 기존 입력이 있으면 명시 선택 없이 덮어쓰지 않는다. 회사/자료/요청/질문 버전이 바뀌면 제안을 다시 확인한다. 같은 선택을 반복해도 대조 쌍을 중복 생성하지 않는다.

## 검증 범위

합성 로컬 후보와 모의 AI의 정확 인용/부적합 출력, pending 제외, 다른 회사·질문·자료 버전 거절, 교정 뒤 잘못된 위치 미표시, 선택 전 DB 무변경, 선택→기존 편집→미검토 저장→과거 답변 보존을 검사한다. 실제 외부 AI의 의미·작성 품질과 사용자 자료 전송은 별도 G06 검증으로 남긴다.

최종 고정 소스 120파일 3,712개 테스트·lint·타입·격리 빌드와 실제 합성 API/UI 검증을 통과했다. 선택 자료 변경 시 전송 승인 해제, 답변 항목 수정 시 이전 제안 해제, 명시 교체 후 별도 저장, 보완/실사 v2의 미검토 상태와 v1 보존을 확인했다. 실사 답변의 이전 검토자는 해제하고 답변 담당자·추가 확인 메모는 보존했다. 콘솔 오류·경고 0, 가로 넘침 없음이다. 실제 외부 AI·기관 실행은 없었으며 사용자 자료·기존 서버를 보존했다. 상세 증거는 `../web/VALIDATION.md`를 따른다.
