# 품질 검증 후보 세트의 버전 등록

기준: 2026-09-27. 아래 설계의 로컬 후보 등록·조회·다운로드·복구·백업 연결은 구현했다. 최종 검증 기록은 `3단계_기획반영_개발현황.md`와 `web/VALIDATION.md`에 있다. 아래는 설계 근거이며 실제 AI 품질 검증 완료를 뜻하지 않는다.

## 목적과 현재 상태

기존 50개는 원고와 기대 동작을 고정한 개발 회귀 세트다. 제조·소프트웨어·서비스 및 신규·재확인을 다루는 추가 12개는 AI가 작성한 합성 후보이며, 원자료와 신청 주제만 있다. 사람 정답표·독립성·실제 AI 품질평가가 완료되지 않았으므로 기존 평가에 합치거나 독립 검증 62건으로 집계하지 않는다.

다음 구현은 이 12개 후보의 정확한 원문을 버전별로 로컬 등록·조회·다운로드하는 기능이다. 외부 AI 실행이나 실제 기업 자료 수집을 포함하지 않는다. 기존 평가 회차·원문·JSON 다운로드는 변경하지 않는다.

## 저장 계약

- 기존 `PlanQualityStore`의 경로 보호·트랜잭션·총 용량 한도를 재사용한다. `quality.sqlite`에 후보 버전과 요청 영수증용 불변 테이블을 추가한다.
- 서버가 저장소에 포함된 후보만 읽는다. 요청 본문으로 임의 회사자료나 새 평가 원문을 받지 않는다.
- 등록본은 `setId`, `version`, `previousVersion`, `previousDigest`, `sourceDigest`, `manifestDigest`, 등록 시각, 요청 번호와 전체 후보를 고정한다.
- `synthetic: true`, `authoredBy: ai`, `humanAnswerKey: null`, `independentHoldoutConfirmed: false`, `performanceEvaluation: not-performed`를 보존한다. 등록 확인을 독립 검증이나 정답표 승인으로 해석하지 않는다.
- 기업정보·자료 본문·신청 주제의 입력 해시와 작성자 메모 해시를 구분한다. 작성자 메모·도전 태그·자료 설계 설명은 사람 검토 화면에만 표시하고 향후 생성 모델 입력에는 포함하지 않는다.
- 같은 요청 번호와 내용은 최초 등록본을 재현한다. 내용이 달라지면 거절한다. 새 요청 번호라도 같은 후보 원문을 중복 버전으로 등록하지 않는다. 등록 전 버전 충돌·소스 변경·용량을 검사한다.

## API와 화면

- 후보 세트 목록 GET: 현재 코드의 후보 목록·해시와 등록 이력을 구분해서 반환한다.
- 버전 등록 POST: `expectedVersion`, `clientRequestId`, `sourceDigest`, `acknowledgedCandidateStatus: true`를 받는다.
- 정확한 버전 GET 및 JSON 다운로드: 현재 코드에서 다시 생성하지 않고 보관한 바이트를 반환한다.
- 요청 영수증 GET: 응답 유실 시 저장 여부를 조회한다. `not-observed`는 미접수 확정이나 자동 재전송 허가가 아니다.
- 기존 설정의 별도 품질 개발 도구 안에서 제공한다. 일반 사용자 메뉴 세 개는 유지한다.

## 백업 호환성

`scripts/local-data-quality.mjs`는 현재 정확히 3테이블과 6트리거를 검사한다. 후보 테이블 추가와 함께 기존 3테이블·새 5테이블 구조를 모두 검증·복원하도록 변경해야 한다. 임의 스키마를 허용하지 않으며 후보의 버전 연결·해시·nonce와 과거 바이트를 검사한다. 회사 자료 백업과는 분리한다.

## 필요한 시험

1. 12개 입력·메모 해시와 원문 고정, 코드 변경 후 과거 다운로드 불변.
2. 작성자 정답 힌트가 모델 입력에 들어가지 않음.
3. nonce 재현·내용 충돌, CAS 경합, 응답 유실 조회·초안 보존.
4. 행·해시·버전 체인 손상 거절, 버전·용량 상한.
5. 기존 50개 평가 이력·내보내기 바이트 유지.
6. 기존 백업과 후보 포함 백업의 검사·복원, 회사 DB 무변경.

로컬 후보 등록 구현에는 추가 사용자 결정이 필요하지 않다. 사람 정답표, 독립 세트 구성·동결, 평가 담당자 및 실제 AI 실행 범위·비용 승인은 실제 품질 검증 전에 별도로 확정해야 한다.
