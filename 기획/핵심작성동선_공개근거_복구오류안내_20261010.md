# 공개 근거 복구 오류 안내 개선

## 구현 결과

공개 근거의 저장 상태를 확인할 때 응답 형식 오류나 서버 오류의 상세 내용이 화면에 그대로 나오던 경로를 수정했다. 화면은 미리 정한 안내만 표시하며 저장 미확인, 다른 창에서 처리 중, 브라우저 기록 접근 실패, 브라우저 잠금 미지원으로 구분한다. 원격 오류의 메시지나 reason 필드는 로컬 오류 분류로 신뢰하지 않는다.

제품 변경은 public-evidence-recovery.ts와 public-evidence-panel.ts 두 개다. 저장소 접근 오류는 getItem/setItem/removeItem 및 localStorage 접근 지점에서 구분한다. 기존 원래 회사/sourceId/revision/항목/digest와 정확한 결과 대조, 잠금, 전송 전 기록, 입력 보존을 유지했다. 복구 실패를 저장 성공이나 확정 실패로 바꾸지 않고 자동 재전송하지 않는다. 새 writer·승인·본문 브라우저 복제는 없다.
