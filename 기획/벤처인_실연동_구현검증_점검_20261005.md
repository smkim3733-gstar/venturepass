# 벤처인 실제 연동의 구현·검증 조건 점검

점검일: 2026-10-05 06:03 KST
소스 기준: `codex/continue-development`, `47b9668`. 별도 편집기 변경3개와 보호 미추적4개 제외.
범위: 소스/기존 인계와 공식 공개 페이지 읽기. 실제 계정·고객자료·운영 DB를 열거나 로그인·입력·첨부·신청·납부·서명하지 않았다.

## 판단

자료0~100개 보관, 선택 근거 초안·보완/새 버전, 수동 공개 출처, 벤처인 연결/선택 입력/복구와 수동 후속 기록의 화면 연결은 구현돼 있다. **현재 공식 사이트의 종단 간 신청·접수·결과 자동화는 완료되지 않았다.** 합성 시험의 성공을 실제 사이트 성공으로 대체하지 않는다.

기존 실행은 선택한 빈 항목에 텍스트·단일 선택값·파일을 전달하고 화면에서 대조하는 기능이다. 새 최종 제출 명령이나 공식 접수증/결과 수집 구현을 추가하려면 인증 뒤 실제 양식·동작·신청 식별자와 공식 지원 범위를 먼저 확인해야 한다. 이번 점검에서 기존 승인/복구를 유지하면서 바로 추가할 수 있는 근거가 확보된 실행 기능은 찾지 못했다. 화면 요약을 다시 쪼개거나 가상의 접수 API/결과 양식을 만들어 독립 개발 완료 수를 늘리지 않는다.

## 공식 공개 자료 확인

2026-10-05에 [공식 확인절차](https://www.smes.go.kr/venturein/institution/processGuide)를 다시 읽었다. 신청서/첨부의 최종 제출, 기관 서류 확인·보완, 수수료 납부에 따른 접수완료가 별도 단계이며 확인서는 My 벤처의 이력에서 출력하도록 안내한다. 이 공개 설명은 실제 계정 화면의 제어 방식이나 접수증 구조를 제공하지 않는다.

[공식 로그인](https://www.smes.go.kr/venturein/auth/viewLogin)에는 ID/비밀번호와 로그인 후 등록하는 공동인증서 안내가 있다. 이 확인은 특정 계정의 인증 방식/성공이나 자동화 허용 판정이 아니다.

제한된 공개 검색에서도 벤처인 신청·최종 제출·계정별 결과 조회 API의 개발명세를 확인하지 못했다. 검색에서 나온 다른 서비스의 채용정보/지원사업 공고 API를 벤처인 제출 API로 사용하지 않았다. 검색 부재는 API가 없다는 증명이나 자동화 허용의 근거가 아니다.

## 결정이 필요한 다음 점검 하나

**사용자가 직접 로그인한 지정 회사 한 곳의 신청·진행 화면을, 입력·첨부·제출 없이 읽는 연동 점검을 진행할지 결정한다.**

승인 전에는 실행하지 않는다. 이번 자동개발 범위에서 실제 로그인·고객 전송을 제외하라는 지시가 유지돼 있으므로 별도 결정이 필요하다. 비밀번호/인증번호를 채팅으로 받지 않는다.

승인되는 경우의 구체 범위:

1. 사용자가 대상 회사 한 곳과 사용할 계정을 지정하고 공식 창에서 로그인/추가 인증을 직접 완료한다. 다른 회사/신청으로 전환하지 않는다. 기존 고객 서버 재시작·운영 DB/계정 저장 변경을 이 점검 권한으로 포함하지 않는다.
2. 현재 열린 공식 화면과 사용자가 직접 연 신청·진행/이력 화면에서 필드 구조, 파일 제약, 단계/버튼 의미, 기존 신청 식별·상태 표시 방식만 읽는다. 저장·동의·접수 시작·최종 제출·납부·서명 및 입력 이벤트를 호출하지 않는다. 기존 workflow 관측 POST도 로컬 DB를 쓰므로 이 첫 점검의 무쓰기 경로로 사용하지 않는다.
3. 고객 값·계정/쿠키·URL query·원문 캡처를 Git/일반 로그/외부 검색/AI 요청에 남기지 않는다. 구현에 필요한 구조만 비식별 기술 기록으로 정리한다. 범위를 넘는 동작이 필요한 화면은 미확인으로 남긴다.
4. 실제로 확인한 구조와 미확인 구간, 공식 지원의 확인 범위를 분리해 기존 입력/복구의 적용 가능성을 판단한다. 그 결과로 최소 어댑터/회귀 범위를 확정한다. 이 읽기 승인은 자동 제출 구현의 운영 실행 승인이나 실제 접수 성공이 아니다.

## 다른 미완료 항목

- KOSIS 통합검색 후보 수집은 구현/합성 검증 상태다. 실제 운영 연결은 사용 권한이 있는 키가 설정되지 않아 미검증이다. 키를 대신 발급·복사·설정하지 않았다.
- 공개 원문/수치 자동 수집과 주장 자동 사실 검증은 미완료다. 현재 기능은 고정 일반 주제 후보 조회, 담당자가 읽고 기록한 출처, 선택 보완, 화면/내보내기 표시다. 실제 원문 API의 인증/이용 범위 및 해당 데이터의 적용 조건을 확정하지 않고 신뢰된 근거 수집으로 승격하지 않는다.
- 실제 AI 의미 품질 개선·사람 내용 인수는 합성 회귀와 별도로 남는다. 이전 승인된 유료 생성/검토는 모두 소비됐으며 반복하지 않는다.
- 보호된 편집기 변경은 이 점검의 완료에 포함하지 않는다.

## 중단과 재개

4G4의 소스·공개 지원 점검은 완료했다. 전체4G/전체제품 완료 선언은 아니다. 현재 허용 범위에서 근거를 갖춰 진행할 다음 실연동 구현 단위를 확정할 수 없어, 위 한 가지 결정 대기로 자동 후속을 PAUSED로 전환한다. 사용자 재개/범위 지정 후 최신 루트 인계부터 읽고, 같은 검사·가상 시연을 반복하지 않는다.

문서만 변경했다. 앱·API·schema/DDL·승인·예산·고객 서버/자료·키·운영 원장 변경0. 이번 테스트/빌드/브라우저 재실행0, 실제 로그인/고객 전송/AI·신청·납부·서명0, 새 채팅/하위 에이전트0. 실제 외부 접근은 위 공식 공개 웹 조회뿐이다.
