## 제안과 채택

자료의 종류와 기업정보를 바로 변경하지 않고 읽기 전용 미검토 제안을 만든다. 첫 구현은 현재 등록 본문 또는 사용자가 명시 선택한 판독 결과의 문서 표제·필드 표기에서 후보를 찾는 로컬 규칙 방식이다. 규칙 버전과 사용한 정확한 자료/결과 버전을 제안에 남긴다. 근거가 모호하거나 후보가 여러 개면 선택을 요구하며 값의 진위·최신성을 판정하지 않는다. 파일명만으로 확정하지 않고 원문 근거가 없는 값은 생성하지 않는다.

종류 제안은 기존 sourceKinds 안에서 근거 표제와 함께 표시한다. 기업정보 제안은 회사명·사업자등록번호·명시 설립일·업종·납입자본금·결산월의 기존 필드에 한정한다. 개업일을 설립일로 변환하지 않는다. 명시 표기가 없거나 날짜의 용도·금액 단위·법인 자본인지 불명확하면 값 대신 확인할 항목으로 남긴다. 납입자본금은 원 단위가 명시되어 기존 필드에 그대로 넣을 수 있는 경우만 후보로 만든다. 업종을 KSIC로 추정하거나 연 매출·실적·권리자를 채우지 않는다.

화면에서 현재 값과 제안 값·정확한 원문·위치를 나란히 보고 항목별로 채택한다. 채택 전 회사 revision, 해당 자료/결과 버전과 텍스트 SHA, 원본이 있으면 원본 SHA, 현재 필드 값과 선택한 값이 일치해야 한다. 같은 필드의 여러 후보를 함께 적용하지 않는다. 사용자가 확인한 선택값만 기존 profile 검증을 통과해 저장한다. 첫 제안을 그대로 사실 확인 또는 진단 요건 충족으로 표시하지 않는다. 판독 결과의 미검토 본문을 이 경로로 분석 근거 전체에 자동 편입하지 않는다.

채택은 nonce·정확한 입력 digest·CAS와 선택 출처의 추가 이력을 함께 저장한다. 이전 필드 값/선택값·자료/결과 ID·위치·규칙 버전·시각을 보관하고, 프로필 변경 시 기존 근거 무효화 규칙을 적용한다. 자료 종류 변경도 등록 자료 수정으로 처리하며 과거 원고/참조를 소급 변경하지 않는다. 기존 기업정보 수동 편집은 보존한다.

## 안정적인 위치

인용의 기본 위치는 정확한 본문 버전의 문자열 시작/끝 인덱스와 원문이다. 매칭 전에 공백이나 숫자를 임의 정규화하지 않는다. 하나의 인용이 여러 곳에 있으면 각 구간을 별개로 제시한다. 줄 번호는 원문 기준이며 편집 후 새 버전으로 취급한다.

PDF/OCR의 실제 페이지, XLSX의 시트·행/셀, SRT/VTT가 제공하는 실제 시간 범위는 해당 추출 결과의 위치 표기와 함께 연결한다. 음성에 시간 정보가 없으면 미확인으로 둔다. 모든 텍스트에서 페이지 번호를 추정하지 않는다. 현재 본문에 임의로 입력된 위치 설명과 추출기가 제공한 구조는 구분한다.

## 검증

합성 문서의 명시 표제, 중복/상충 값, 다른 회사 번호, 모호한 날짜·단위, 누락 근거, 문자 범위·정확 인용·원문 변경을 검사한다. 미검토 제안의 불변성, 항목별 채택, 사용자 기존 값 충돌·nonce 재확인, 프로필 검증 실패의 원자성, 근거 변경 후 분석 무효화와 과거 출처 이력 보존을 확인한다. 실제 문서 인식률이나 기업정보 정확성은 사람이 원본을 대조한 별도 품질 검증이다.
