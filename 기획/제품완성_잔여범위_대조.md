# 제품완성 잔여 범위 대조

기준일: 2026-09-25. 원기획과 현재 제품 소스를 대조한 범위 감사다. 실제 회사 자료·DB·계정·공식 사이트를 읽거나 변경하지 않았다. 로드맵 14~16의 기능이 완료된 상태를 가정해 그 이후의 잔여 범위를 정리했다. 해당 기능의 최종 통합 검사 결과는 별도 검증 기록을 따른다.

최신 상태(2026-09-26 01:12): 아래 원감사 표의 R01~R11은 후속 17~29 구현과 최종 3,712개·타입·lint·격리 빌드·API/UI 검사로 모두 닫았다. 원감사 표는 당시 차이의 근거로 보존하며, 현재 미완료 기능 목록으로 해석하지 않는다. G01~G06의 실제 검증·자료·운영 결정은 남아 있다.

## 1. 판정 기준

- **독립 구현 잔여**: 원기획에 동작이 직접 명시돼 있고, 현재 동등 기능으로 충족되지 않는 부분. 합성 자료로 개발·검증할 수 있다.
- **부분 구현**: 수동 처리나 일부 데이터 연결은 있으나 원기획의 자동 처리·이력·출처 연결이 빠진 부분. 기존 기능을 다시 만들지 않고 차이만 구현한다.
- **동등 구현**: 전용 화면 이름이나 구현 방식이 달라도 요구 동작을 현재 기능으로 수행할 수 있는 부분. 새 기능으로 재등록하지 않는다.
- **실제 검증·운영 결정**: 관측하지 않은 기관 화면, 실제 회사 사실, 외부 전송·서비스 운영 조건이 필요한 부분. 로컬 개발 전체를 중단할 이유는 아니지만, 모의 검증을 실제 성공으로 표시하지 않는다.
- **품질 검증 또는 고도화**: 기획의 검증 기준·예시와 향후 개선 방향. 별도 제품 화면이나 자동 판단 기능이 필수라고 확대하지 않는다.

이 문서는 새로운 제품 요구를 추가하지 않는다. 아래 식별자를 잔여 범위의 기준으로 사용하고, 추가 요구가 생기면 원기획의 직접 근거와 기존 동등 기능을 함께 확인한다. 법령·기관 운영 규칙의 현재 효력을 재검증한 문서는 아니다. 기획에 적힌 기한을 새로운 자동 계산 규칙으로 바로 적용하지 않는다.
