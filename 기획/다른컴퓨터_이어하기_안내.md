# 다른 컴퓨터에서 벤처패스 이어서 개발하기

GitHub 저장소: https://github.com/smkim3733-gstar/venturepass (기본 갈래 `main`)

## 1. 한 번만 설치할 것

1. **Git**: https://git-scm.com 에서 설치합니다. 처음 push할 때 GitHub 로그인 창이 뜨면 대표님 계정(smkim3733-gstar)으로 로그인합니다.
2. **Node.js 24**: https://nodejs.org 에서 24 버전을 설치합니다.
3. **pnpm 11.19.0**: 명령 창(PowerShell)에서 실행합니다.

```bash
npm install -g pnpm@11.19.0
```

4. **Claude 데스크톱 앱**(Code 탭) 또는 Claude Code를 설치하고 같은 계정으로 로그인합니다.

## 2. 내려받기와 준비

OneDrive 바깥 폴더를 권장합니다. OneDrive 안에서는 시험이 몇 배 느립니다. 예: `C:\dev`

```bash
git clone https://github.com/smkim3733-gstar/venturepass.git C:/dev/venturepass
```

```bash
cd C:/dev/venturepass/web && pnpm install --frozen-lockfile
```

AI 기능을 쓸 때만: `web/.env.example`을 복사해 `web/.env.local`을 만들고 `OPENAI_API_KEY=` 뒤에 키를 직접 넣습니다. 키는 채팅에 붙여 넣지 마세요.

실행해 보기:

```bash
cd C:/dev/venturepass/web && pnpm dev
```

브라우저에서 http://127.0.0.1:3000/studio 를 엽니다.

## 3. Claude에게 이어서 시키기

Claude 앱에서 `C:\dev\venturepass` 폴더를 열고 이렇게 말하면 됩니다.

> 작업대장 보고 자동 연속 개발로 이어서 진행해줘

저장소 맨 위의 `CLAUDE.md`에 한국어로만 대화하기, 자동 진행·자동 push 승인, 하지 말아야 할 일, 커밋 전 점검 순서가 적혀 있습니다. 새 컴퓨터의 Claude도 이 파일을 자동으로 읽습니다.

## 4. GitHub로 옮겨지지 않는 것

| 항목 | 이유 | 새 컴퓨터에서 |
|---|---|---|
| `web/.env.local`(API 키) | 비밀값이라 올리지 않음 | 2단계처럼 직접 다시 만듭니다 |
| `web/.venture-pass`(이 PC 앱에 넣은 회사 자료) | 회사 자료라 올리지 않음 | 2026-10-25 기준 실제 회사 자료는 없고 가상 시험 자료만 썼습니다. 새로 시작하면 됩니다 |
| `샘플자료` 폴더 | 회사 자료라 올리지 않음 | 2026-10-25 기준 비어 있습니다. 넣게 되면 USB나 OneDrive로 직접 복사합니다 |
| 저장된 벤처인 계정 | Windows 보안 기능(DPAPI)으로 그 PC에서만 풀리게 암호화됨 | 새 컴퓨터에서 다시 등록합니다 |
| 이 PC Claude의 기억 | 컴퓨터별로 저장됨 | 필요한 내용은 `CLAUDE.md`에 옮겨 두었습니다 |

## 5. 두 컴퓨터를 번갈아 쓸 때

- 작업을 시작하기 전에 최신 내용을 받습니다(Claude에게 "최신 내용 받아줘"라고 해도 됩니다).

```bash
cd C:/dev/venturepass && git pull
```

- 한 컴퓨터의 작업이 GitHub에 올라간 뒤에 다른 컴퓨터에서 시작하세요. 두 곳에서 동시에 고치면 내용이 엇갈릴 수 있습니다.
