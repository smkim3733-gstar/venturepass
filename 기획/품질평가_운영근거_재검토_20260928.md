## 2026-09-29 00:07 KST SDK 대조

설치된 OpenAI JavaScript SDK 7.20.0의 `src/resources/responses/responses.ts`에 Responses 생성 입력 `truncation?: 'auto' | 'disabled' | null`이 존재하며 deprecated 주석도 확인했다. 같은 주석은 disabled를 기본값으로 설명하고 문맥 초과 시 400 오류를 명시한다. 이번 근거 갱신에서는 기존 `truncation: disabled` 요청 본문·모델·예약 산식을 유지했다.
