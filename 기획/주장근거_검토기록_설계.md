# 20. 주장과 근거의 검토 기록

상태: 구현·전체 회귀·독립 검토·격리 API/UI 검증 완료. 잔여 범위 R05의 명시된 문장별 주장·상태·검토 방식·담당자·기한을 연결한다. 자료 변경의 영향 목록(R06)은 이 기록과 기존 이력의 정확한 참조를 재사용한다.

## 기존 기능을 재사용할 부분

원고 항목의 인용, 검토 의견 판단 이력, 수치 대조, 실사 답변을 다시 구현하지 않는다. 원고의 정확한 문장에 안정적인 주장 ID를 부여하고 사용자가 설명한 성격과 확인 방식을 따로 보관한다. 사용자가 연결한 기존 수치 대조/검토 판단의 정확한 버전은 참고 참조로만 연결한다. 그 결과를 사실 확인이나 심사 적합성으로 승격하지 않는다.

## 최소 기록

- 정확한 원고 ID·버전·항목 키·원문 그대로인 주장 인용. 임의 새 문장을 검증된 원고인 것처럼 만들지 않는다.
- 주장 성격: 미확인 / 현재 사실에 관한 주장 / 향후 계획 / 가정. ‘현재 사실에 관한 주장’은 기록 분류이며 사실 검증 완료가 아니다.
- 대조할 등록 자료의 정확한 버전·인용·위치. 원본만 보관한 자료는 인용 공란·본문 미확인으로 연결한다. 안전한 원본 reader와 교차 SHA 이력 검사를 재사용한다.
- 기업·기간·단위/범위 해석 메모, 확인 담당자, 수동 기한, 다음 확인 사항. 연락처 기록이나 수치의 단위 변환을 자동 가져오지 않는다.
- 검토 방식: 미검토 / 문서 대조 / 기업 진술 확인 / 외부 확인 기록 / 복수 방식. 외부 확인은 담당자가 확인한 대상·내용·일자를 적는 수동 기록이며 앱이 외부 기관을 조회했다는 표시는 아니다.
- 담당자 판단: 미검토 / 일치한다고 판단 / 충돌 발견 / 근거 부족. 판단 이유·판단자·확인일을 함께 보관한다. ‘일치’는 문장과 자료의 대조에 관한 담당자 판단으로 표시하고 진위를 보장하지 않는다.

최초 기록은 미검토. 후속 버전에서 실제 담당자 판단을 입력할 수 있으며 주장·인용·해석을 수정하면 화면의 판단 선택을 미검토로 되돌린다. 근거 변경 뒤 과거 판단은 보존하고 현재 연결의 재확인 필요를 별도로 표시한다.

같은 주장 이력의 항목 키는 고정한다. 사용자가 같은 항목을 가진 새 원고 버전을 명시 선택해 재연결할 수 있으며, 이때 주장 인용과 원고 검토 판단 참조를 다시 지정한다. 이전 원고·문장·SHA와 판단은 과거 버전에 남는다. 안정 주장 ID의 유지나 재연결은 두 문장의 의미가 같다는 자동 판정이 아니다.

## 저장·화면 경계

strict append-only mutation, revision CAS, 고유 nonce/입력 digest와 정확한 이전 버전 확인을 사용한다. 주장별 안정 root ID와 매 버전 ID·서버 시각을 둔다. 회사당 최대 200개 버전/30만 자, 한 버전의 자료 10개·원본 24MiB, 인용 1,500자, 요청 512KiB로 제한한다. 저장 한도 초과는 과거 기록을 삭제하지 않고 거부한다.

원고/원본은 기존 frozenPlans/frozenOriginals 공통 목록에 연결한다. 다른 기록을 거쳐 같은 원고 ID·원본 ID의 내용을 바꿔 과거 주장 이력을 덮어쓰는 우회를 막는다. 참조 자료 삭제를 보호하며 저장된 판단 객체를 GET 요청에서 수정하지 않는다. 현재 연결 상태는 조회용 계산 결과로 표시한다.

사업계획서 화면에서 저장 원고의 정확한 항목·문장을 명시 선택하고 근거를 연결한다. 편집 중 기존 원고·검토 의견·수치 대조의 다른 저장을 차단한다. 저장 실패/불확실 응답은 입력을 보존하고 정확한 ACK를 확인한다. 주장 저장만으로 원고의 확인 표시·기관 진행 단계·실제 접수 결과를 바꾸지 않는다. 외부 AI 호출이나 기관 전송은 포함하지 않는다.

## 검증 종료 조건

구형 데이터의 빈 배열 호환, 회사/원고/항목/인용의 정확 일치, 중복 키와 변경된 원문, sourceUpdatedAt/원본 SHA 교차 이력, nonce 재전송/충돌·오래된 CAS·최신 버전·한도·저장 실패를 검사한다. 성격과 판단의 구분, 처음 미검토와 수정 후 초기화, 근거 변경 뒤 과거 판단 보존, 기존 원고/수치/기관 상태 불변을 실제 합성 API와 화면에서 확인한다. 자동 의미 일치·권리·법적 효력 판정은 추가하지 않는다.
