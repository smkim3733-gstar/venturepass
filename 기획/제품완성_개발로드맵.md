# 벤처패스 제품 완성 개발 로드맵

기준일: 2026-09-25. 사용자는 특정 회사의 추가 자료가 없다는 이유로 제품 개발이 멈추지 않도록, 벤처패스를 끝까지 연속 개발하라고 재확인했다. 기존 서비스 기획 v1.5 및 사전진단 기능설계를 제품 범위의 기준으로 사용한다. 개별 회사의 실제 신청 결과와 제품 기능의 구현 상태는 분리한다.

## 완료 기준과 진행 원칙

- 제품의 완료 기준은 자료 수집·추출·검토, 사전진단, 아이템 도출과 원고, 제출 준비와 승인 후 실행, 접수 이후 요청·결과 추적까지 연결된 사용자 흐름이다. 테스트 개수 또는 한 기능의 완료만으로 전체 제품 완료를 선언하지 않는다.
- 실제 기관 동작은 관측된 화면·인증·이용 범위에 한해 구현한다. 회사 자료가 부족하면 해당 실제 신청은 미확인으로 두되, 자료와 무관한 제품 구현·가상 자료 검증·로컬 운영 검증을 계속한다.
- 개인 자료·자격정보를 Git·로그·외부 AI에 전송하지 않는다. 실제 사이트 전송·동의·최종 제출·납부·권한 확대는 필요한 정확한 승인을 별도로 받는다. 새로운 계정·공유·외부 서비스·배포를 임의로 활성화하지 않는다.
- 주기적 재개는 의미 있는 진전·실패·필수 사용자 조치만 알린다. 같은 자료 질문이나 변동 없는 상태 보고를 반복하지 않는다.
