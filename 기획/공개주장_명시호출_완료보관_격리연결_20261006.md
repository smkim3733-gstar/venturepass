## 3. 원래 영수증 보관과 정상 결과 수락

동기 operation 자체와 그 response/completion/inspect 함수 참조를 await 전에 보관한다. 이후 operation 멤버/호출자의 옵션을 바꿔도 원래 Promise와 함수만 관측한다. 원래 Promise의 성공/거절 관측을 즉시 설치한다. 불완전한 영수증에서도 얻은 원래 Promise의 거절을 관측하고 얻은 Response는 receiver를 통해 자기 본문 정리 대상으로 유지한다.

성공 후보는 전용 receiver의 누적 byte·EOF/reader 정리·fatal UTF-8·정규 wire 검사를 거친 값뿐이다. 임의 외부 DTO를 나중에 주입하는 통로는 없다. query8KiB·DTO4MiB·성공 전체4MiB+8KiB/오류8KiB 한도와 기존 고정 오류를 그대로 쓴다.

성공 delivery는 요청과 응답 completion 모두를 관측하고 정리 실패가 없을 때만 반환한다. display(frame)는 다시 현재 ticket.accept를 통과해야 결과를 내준다. 실패도 ticket.isCurrent를 통과해야 표시된다. delivery 사본을 변경하거나 이전 display 사본의 본문/금액을 바꿔도 내부 후보와 이후 표시를 변경할 수 없다.

historical의 not-checked와 inspect-current의 exact/changed/unavailable은 기존 ticket 조건을 따른다. 원래·관측·화면 revision 대조를 보존하고 현재성을 과거 의견·수동 판단·원고 채택 권한으로 합치지 않는다. 회사/선택/snapshot/revision·편집/차단/닫힘·ticket 변경 시 caller는 기존 표시를 지워야 하고 display 역시 늦은 성공/오류를 거절한다.

## 4. completion과 보관 책임

| 관측 | 의미 | 정상 폐기와 구분 |
| --- | --- | --- |
| delivery | 빠른 고정 오류 또는 양쪽 정상 정리 후 성공 사본 | 표시 가능성은 현재 ticket에서 별도 확인 |
| requestCompletion | 원래 요청 영수증의 completion 및 settled 관측 | cleanupFailed는 sticky로 남음 |
| responseCompletion | 원래 receiver의 start/read/cancel 종료 | 늦은 Response와 취소 Promise가 남으면 pending |
| completion / settled | 양쪽 원래 I/O 종료, 또는 요청 미시작이 확정된 수신 종료 | 서버 SQL/guard/lease·원래 명령 복구 종료가 아님 |
| canForget | I/O 종료·유효한 영수증·양쪽/관측자 정리 실패 없음 | 서버 service의 보관/복구를 해제할 근거가 아님 |

성공 본문 EOF 뒤에도 요청 completion이 남아 있으면 표시하지 않는다. 이 구간의 화면 abort도 빠르게 전달하기 위해 원래 외부 signal 관측을 유지하며, 관측자 제거 실패는 별도 observerCleanupFailed로 보관한다. 취소한 호출의 display는 항상 null이고 같은 객체를 다시 시작할 수 없다.

빠른 오류 뒤에도 원래 operation과 receiver는 계속 보관한다. cancel throw/reject, 원래 read/cancel 지연, inspect 실패·completion 거절은 정리 실패를 숨기지 않는다. 주입 후 throw/Promise 영수증·completion/inspect 누락은 request unavailable이다. 이 경우 이미 Request가 시작됐는지 알 수 없으므로 미시작/정상 완료로 추정하지 않고 전체 completion을 pending으로 남긴다. 타이머로 영수증을 보충하거나 새 요청을 만들지 않는다.

호출 객체는 전역 registry·영속 보관자나 서버 owner가 아니다. 화면 참조를 지운 뒤에도 호출자가 강한 참조를 유지해야 한다. 실제 React 부모의 보관 한도와 화면 간 교체/폐기 구현은 후속 계약 대상이다. 브라우저/프로세스 종료·PC 전원 차단 후의 영속 보관을 보장하지 않는다.
