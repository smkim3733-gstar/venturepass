## 실제 실행 전에 필요한 사항

실제 AI 품질 검증에는 사용할 자료·제공자·목적·비용 범위가 명확한 승인이 필요하다. 공식 사이트에는 현재 계정·회사·화면·정확한 입력 및 첨부·법적 동의·최종 제출·납부를 구분하여 기존 승인 범위부터 확인한다. 가상 자료를 공식 기관에 제출하지 않는다. 공식 미관측 동작을 추측해서 구현 완료로 표시하지 않는다.

기존 개발 서버와 사용자 자료·원본·미커밋 작업은 보존했다. Git push·공개 배포·실제 기관 실행은 수행하지 않았다. 이번 후속 범위는 v2 별도 전송 승인·합성 관측/정산·중단 복구·v6 백업이다. 다음 검토 화면 연결을 위한 자동 연속 개발 예약은 활성 상태다.
