# 외부 추출·전사의 중단 복구

상태: R03 잔여의 저장·공급자·서비스·API·화면 구현과 범위 검사, 독립 검토, 고정 전체 검사와 격리 API/UI 검증을 완료했다. 23의 로컬 문서/OCR 재개와 원본 보관·본문 채택 경계를 재사용한다. 실제 사용자 자료의 외부 전송을 승인하거나 실행하는 문서가 아니다. 개발 검증은 합성 파일과 모의 응답으로 진행한다.

## 완료 지점을 보관

23의 원본 접수·소유 정보·해시·회사별 잠금·본문 검토 후 채택을 재사용한다. 외부 처리는 로컬 판독 실패 시 자동 전환하지 않는다. 파일 하나와 처리 방식·전송 대상·목적을 표시하고 사용자가 해당 요청을 명시 선택하는 경로로 한정한다.

네트워크 호출 전에 정확한 원본 SHA·방식·모델 설정의 식별 정보와 승인한 요청을 DB에 기록한다. 키·자격정보는 기록하지 않는다. 공급자가 반환한 성공 결과는 미검토 판독문으로 저장한 뒤 응답한다. 화면 응답이 유실돼도 같은 요청 번호로 저장 결과만 확인하며 성공한 외부 호출을 반복하지 않는다.

## 결과 불명확 상태

외부 요청 시작 이후 서버 종료·네트워크 단절·취소가 생겼고 결과 저장이 확인되지 않으면 외부 처리 결과 미확인으로 둔다. 오류나 시간 초과만으로 공급자가 처리하지 않았다고 판단하지 않는다. 자동 재시도·로컬 재개 버튼의 외부 재전송은 금지한다.

공급자 조회로 결과를 안전하게 복원할 수 있는지는 기존 API의 실제 기능을 확인한다. 가능하지 않으면 미확인 상태와 중복 처리·비용 가능성을 보여 주고, 새로운 명시 요청 없이 재전송하지 않는다. 원본과 이전 시도 식별 이력은 보존한다. 앱의 요청 취소는 공급자의 처리 취소·비용 취소 성공을 뜻하지 않는다.

## 결과 검토

추출·전사 결과는 분석 본문과 분리한다. 정확한 원본과 결과를 대조하고 교정한 본문을 명시 채택해야 한다. 실제 시간 정보가 없는 음성 결과에는 타임스탬프를 만들어 넣지 않는다. 결과 보관 한도·원문 좌표·원본 변경 검사·본문 정리와 채택 이력은 로컬 경로와 같은 원칙을 적용한다.

## 완료 검사

승인 없음/다른 파일·방식/해시 변경 요청 거부, 요청 시작 전 실패, 성공 결과 저장 후 응답 유실, 시작 후 결과 불명확, 재시작 뒤 자동 재전송 차단, 늦은 응답과 다른 회사/시도 덮기 거부, 명시 재요청의 분리된 이력을 모의 공급자에서 검사한다. API 키·회사 원문을 로그에 출력하지 않는다. 실제 외부 품질·비용·사용자 자료 전송은 별도 승인과 검증 항목으로 남긴다.
