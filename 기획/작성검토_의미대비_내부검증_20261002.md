## 검증 결과와 한계

- 관련 Vitest 4파일 **36개** 통과: 신규 13개와 기존 23개. 사례를 기존 표현 점검·표시·개별 판단 입력에 연결해 원문 인용·저장 의견·원본 번호·확인 필요 표시를 유지하는지 검사했다. 의미 판단의 정확도를 자동 판정한 시험이 아니다.
- 설치된 Edge의 격리 브라우저에서 **17개 확인 항목** 통과. 원래 React 구성 요소를 가져오되 시험용 배치와 스타일, 저장 미확인 모의 응답을 사용했다. 전체 Next 앱·고객 DB·기관 제출의 종단 간 검증이나 사람 인수 시험이 아니다.
- 영어 분류 4개를 한국어로 편집하면 안내가 사라지지만 원문 인용과 원래 저장 원고는 바뀌지 않는다. 빈 의견도 사실·증빙 확인 필요 안내를 유지한다.
