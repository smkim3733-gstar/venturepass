# 공개 통계 후보 조회와 근거 보관

현재 범위는 KOSIS 검색 후보 조회, 선택한 표의 이름·수록 시점·조사 출처 조회, 수동 코드 지정 후 단일 수치 조회, 담당자의 원문 확인·수동 보관입니다. 통계 수치나 원문을 자동 분석하지 않습니다.

## 사용 순서

1. 간단 화면에서 **공개 근거 보완 → 공개 통계 찾기**를 엽니다.
2. 일반 주제를 고릅니다. 보낼 검색어와 KOSIS 목적지를 확인하고 **공개 검색 후보 10개 조회**를 누릅니다.
3. 검색 후보의 수록기간은 원문 표기입니다. 조회 시각은 발행일이나 사람이 읽은 날짜가 아닙니다.
4. 필요하면 **이 표의 기본 정보 확인 (선택)**을 펼치고 표 이름/수록 시점/조사·담당 출처 중 하나를 골라 **선택 표 정보 한 번 조회**를 누릅니다. 검색 후보를 새로 대조한 뒤 고른 정보를 읽으므로 공개 요청은 최대2회입니다. 펼침·선택 변경만으로 조회하지 않습니다.
5. 공식 선택조건의 정확한 코드를 아는 경우 **코드를 아는 수치 1건 조회 (선택)**에서 항목·분류·시점을 입력하고 별도 조회 체크 후 한 번 읽습니다. 결과의 **수치·선택조건을 아래 빈 입력칸에 넣기**로 검토용 기록을 옮길 수 있습니다. 결과를 자동 저장하지 않습니다.
6. **통계표 원문 열기**로 대상·단위·기준 기간을 직접 확인합니다. 주소가 미확인이면 기존 KOSIS 새 창 검색을 이용합니다.
7. 필요하면 **제목·주소를 아래 빈 입력칸에 넣기**를 누릅니다. 기존 제목/주소가 있으면 덮어쓰지 않습니다. 120자보다 긴 제목도 자동으로 자르지 않습니다.
8. 원문 발췌·읽은 날짜·관련 항목을 기록하고 별도 보관 체크 후 저장합니다. 발행일·기준 기간을 모르면 비워 두고 미확인으로 남깁니다.
9. 원고에 사용할 때는 기존 자료 선택 → 별도 AI 전송 동의 → 수정 전후 비교 → 새 버전 채택을 따릅니다.

검색 후보 없음은 해당 사실이나 자료가 없다는 판정이 아닙니다. 조회 실패와 빈 결과를 구분합니다. 공개 산업 정보는 회사 자체의 실적 증거가 아닙니다.

## 현재 PC의 연결 상태와 설정

2026-10-05 개발 확인 당시 KOSIS 인증키가 설정되어 있지 않았습니다. 실제 KOSIS 응답의 운영 검증은 하지 않았으며 테스트는 합성 응답입니다. 키가 없으면 앱 안 조회에 연결 미설정 안내가 나타납니다. **KOSIS에서 검색 열기**와 수동 출처 보관은 계속 사용할 수 있습니다.

실제 연결을 사용하는 설정 담당자는 [KOSIS 공유서비스](https://kosis.kr/openapi/index/index.jsp)에서 사용 권한과 활용 절차를 확인하고 본인에게 발급된 인증키를 사용해야 합니다. [통계정보 활용약관](https://kosis.kr/openapi/introduce/introduce_02List.do)의 출처 표시 및 인증키 관리 조건도 확인합니다. 이 앱이 이용 신청이나 약관 동의를 대신 완료하지는 않습니다.

선택 설정 변수는 서버 전용 **KOSIS_API_KEY**입니다. 기존 로컬 설정 절차에 따라 앱의 .env.local 또는 서버 프로세스 환경에 설정합니다. NEXT_PUBLIC_ 접두사를 붙이지 않습니다. 키를 대화·스크린샷·Git·요청 로그에 남기지 않으며 문서의 예제 키를 사용하지 않습니다. 기존 설정/고객 서버의 변경·재시작은 담당자가 적절한 시점에 별도로 진행합니다. 이번 개발에서 키나 고객 서버를 변경하지 않았습니다.

## 조회 범위와 한계

- [공식 통합검색 API](https://kosis.kr/openapi/devGuide/devGuide_0701List.do)의 검색순 첫 페이지 최대 10개만 요청합니다. 전체 자료 조사나 최신순 판정이 아닙니다.
- 고정 일반 주제 8개만 보내며 회사명·원고·자료 본문·자유 검색문을 자동 추출하지 않습니다. 새 창에서 사용자가 직접 입력하는 내용까지 통제하지는 않습니다.
- 명시 검색은 제공자 요청1회, 표 정보/수치 조회는 후보 재대조 검색과 선택 정보/한 셀을 합쳐 최대2회입니다. 자동 재시도·정기 수집·통계표 전체 원문 조회·영구 저장은 없습니다. 조회 결과는 닫기·선택 변경·화면 이동 때 지웁니다.
- 같은 전송 모듈의 진행 중 요청은 하나로 제한합니다. 명령 전체20초, 제공자 응답 각각512KiB를 넘으면 실패로 처리하며 내용을 자르지 않습니다. 표 정보/수치 명령은 최대2개 응답이며 두 응답 합계512KiB 제한은 아닙니다. 여러 프로세스의 분산 잠금은 아닙니다.
- KOSIS 링크의 기관·표 ID와 경로를 대조해 필요한 ID만 HTTPS 주소로 구성합니다. 실제 원문 접근·정확성·최신성까지 검증하는 것은 아닙니다.
- 제목과 URL을 옮겨도 발췌·읽은 날짜·확인 상태·저장 동의는 채워지지 않습니다. 기존 수동 출처 기록을 신뢰된 구조화 증거나 AI 전송 승인으로 취급하지 않습니다.
- 회사당 0~100개와 기존 파일/본문/AI 입력 한도는 그대로입니다. 검색 후보 10개 제한은 별도의 읽기 범위입니다.


## 화면과 Word·Markdown의 공개 근거 출처 확인

원고가 공개 후보를 인용하면 Word의 ‘부록 6 공개 근거 출처 확인’과 Markdown의 같은 이름 부록에 출처 기록이 표시됩니다. 간단 화면에서는 **AI 계획서 → 추가 자료·AI 다시 작성·내려받기 → 원고·첨부 보관 및 내려받기 → Word 내려받기**로 확인할 수 있습니다.

원문 URL·발행일·자료 기준 기간·담당자가 읽었다고 기록한 날짜는 서로 구분됩니다. 이 표시는 **현재 보관 자료의 수동 기록**입니다. 과거 원고를 내려받아도 원고 작성 당시 출처 이력을 복원하거나 사이트를 새로 조회하지 않습니다. 읽은 날짜와 원고 채택은 사실 확인 완료를 뜻하지 않습니다.

‘같은 문구 있음’은 인용문과 현재 보관 발췌의 문자 대조 결과입니다. 통계 수치·문맥·시점·회사 해당 여부는 따로 확인해야 합니다. 수동 기록의 형식이나 경계가 바뀌어 읽을 수 없으면 URL·날짜를 추정하지 않고 미확인으로 표시합니다. 자료함의 보관 본문을 직접 확인하세요.

부록에는 이 원고가 인용한 공개 후보만 포함됩니다. 담당자 관련성·상충 메모를 함께 보되 회사 고유 실적과 구분하세요. 내보내기는 원고·인용·자료·검토/확인 상태를 저장하거나 바꾸지 않습니다. 간단 화면의 **AI 계획서 → 기준·근거 보기 → 공개 근거 출처 확인**에서도 같은 수동 출처·시점·문자 대조를 볼 수 있습니다. 내려받기 화면의 같은 표시에는 현재 선택한 저장 원고의 인용이 나오며, 미저장 편집은 포함하지 않습니다. 과거 버전을 선택해도 출처 정보는 현재 보관 자료의 기록입니다. 회사·자료 revision·원고를 바꾸면 출처 목록은 다시 접힙니다. URL은 문자로 표시하며 목록을 펼치는 것만으로 외부 사이트 조회·저장·AI 실행을 하지 않습니다.

## 코드를 아는 수치 1건 조회 — 2026-10-05 연결

검색 후보의 **코드를 아는 수치 1건 조회 (선택)**을 펼칩니다. 공식 선택조건에서 직접 확인한 항목 코드1개·분류1부터 순서대로 필요한 코드1~8개·연/월/분기1시점을 입력합니다. 앱이 검증한 코드 목록을 제공하는 기능은 아닙니다. 코드를 모르면 기존 통계표 원문 열기·수동 출처 보관을 사용합니다. 키가 포함된 생성 URL 전체를 입력하지 않습니다.

연은 YYYY, 월은 YYYYMM, 분기는 YYYY01~YYYY04입니다. 전체/합계/최신 시점·중간 빈 분류·범위·복수 코드를 자동 선택하지 않습니다. 공식 문서의 반기 S/H 표기가 달라 이 화면은 반기를 지원하지 않습니다. 같은 코드가 다른 분류 위치에 쓰인 경우 그대로 대조합니다.

별도 조회 체크 후 **선택 수치 한 번 조회**를 누르면 원래 후보 전체를 새 검색과 대조하고 단일 수치를 읽습니다. 최대2개 공개 요청이며 회사 자료는 보내지 않습니다. 입력 변경은 체크/이전 결과를 지우고 주기 변경은 시점을 비웁니다. 시작·펼침·새로고침·입력 변경만으로 조회하지 않습니다. 닫기·상위 검색 접기·부모 주제/후보 변경·화면 이동은 진행 중 요청을 취소하고 늦은 결과를 버립니다.

원래 코드와 반환된 표·항목/분류 명칭·단위·값·시점을 함께 확인하세요. 값은 문자열로 보존하며 단위 환산이나 사실 판정을 하지 않습니다. 빈 문자열과 미확인 정보·빈 행·조회 실패를 구분합니다. 빈 행은 수치0이나 자료 부재·코드 무효를 증명하지 않습니다. 수동 코드 지정과 API 전송 경로를 구분하며 코드 목록의 공적 검증·회사 해당성·사실 확인·주석/표 전체 읽기는 완료하지 않습니다. 행 수정일·조회 시각·발행일·담당자가 읽은 날짜는 서로 다릅니다.

결과는 열린 화면의 메모리에만 있습니다. **수치·선택조건을 아래 빈 입력칸에 넣기**를 누르면 제목·주소·발췌·기준 기간4개가 모두 비어 있을 때만 옮깁니다. 기존 수동 출처 입력은 덮어쓰지 않습니다. 자동 저장/AI 전송·원고 반영은 하지 않으며 기존 자료 보관/AI 전송 동의와 새 버전 채택 절차를 유지합니다.

## 선택한 표의 기본 정보

표 이름(TBL), 수록 시점(PRD), 조사·담당 출처(SOURCE) 중 선택한1종을 명시 조회합니다. 원래 고정 주제/후보 전체를 재대조하며 이름이 비슷한 표로 바꾸지 않습니다. 이 응답 자체에는 기관·표 ID가 없어 요청 대상으로만 연결합니다. 독립적인 표 신원이나 코드 선택 목록의 증거는 아닙니다. 수록 시점은 전체 목록/연속 기간을 보장하지 않습니다. 표 이름0~1행·수록 시점0~32행·조사 출처0~10행을 대조하며 미지원/초과는 실패로 남깁니다.

검색·표 정보·수치는 같은 기본 전송 모듈의 진행 잠금1개를 공유합니다. 명령 전체20초/응답당512KiB·리디렉션 거절·무재시도/취소를 유지합니다. 명시 표 정보/수치 명령은 최대2개 응답이며 두 응답 합계512KiB 또는 여러 프로세스의 분산 잠금은 아닙니다.

## 조회 기록을 수동으로 보관하기

수치 결과를 옮긴 뒤 발췌를 검토하세요. 이 내용은 수동 선택조건과 API 응답 문자를 함께 옮긴 기록이며, 통계표 전체 원문의 발췌나 검증된 공식 증거가 아닙니다. 빈 문자/null·줄바꿈을 구분하려고 문자열 표기를 사용합니다. 단위 환산·회사 주장 사실 확인을 완료하지 않습니다.

제목120자·옮길 발췌50,000자를 넘거나 형식이 맞지 않으면 자동으로 자르거나 일부만 옮기지 않습니다. 발행처·발행일·읽은 날짜·관련성/상충 메모는 채우지 않고 기존 수동 값을 유지합니다. 조회 시각·행 수정일을 발행일/읽은 날짜로 바꾸지 않습니다. 이관 후 보관 체크는 해제되므로 내용을 검토하고 읽은 날짜·별도 보관 동의를 입력해야 저장할 수 있습니다.

이관은 입력칸만 채웁니다. 보관 버튼은 기존 자료 저장을 사용하며 응답이 유실되면 원래 자료 ID로 저장 상태를 조회합니다. 자동으로 다시 저장하지 않습니다. 미저장 입력과 미확인 요청은 현재 창에만 남으며 새로고침 후 자동 복원하지 않습니다. 보관한 자료는 기존 자료함에 남습니다. 원고/AI 이용은 별도 선택·동의·수정안 채택 절차입니다.

이번4H6은 관련162/162개(신규33+기존129)와 격리 Next HTTP/SQLite/Edge6/6흐름으로 확인했습니다. 제공자 응답은 합성이며 이관 서버 쓰기0회·별도 명시 보관1회입니다. [4H6 구현·보관 및 복구 검증](../기획/공개통계_수치기록_수동보관연결_20261005.md)에 자세한 범위를 기록했습니다.

## 검증 범위와 미완료

과거4H5 관련314/314개와 격리 Next HTTP/SQLite/Edge7/7흐름은 합성 제공자 응답을 사용했습니다. 실제 KOSIS 운영 응답 검증은0/1입니다. 키/예제키·고객자료/계정·운영 DB를 사용하지 않았습니다. 자동 코드 목록 조회/분류 순번 매핑·전체 원문/주석·자동 원고 반영·회사 주장 사실 검증은 미완료입니다. 수치 기록의 수동 보관은 위 별도 절차로 연결했습니다.
