# Word 내려받기 보고서 서식 — 2026-10-04

## 적용 범위

사용자 요청은 개별 첨부파일의 재편집이 아니라 앱의 Word 내려받기 출력 개선이다. 기존 `format=docx` 다운로드 경로가 선택한 저장 원고를 보고서로 출력하도록 `studio-export-docx.ts`만 변경했다. 다운로드 버튼, 원고 저장, AI 생성, Markdown 출력, 운영 자료는 변경하지 않았다.

- A4 표지, 내부 이동 목차, 번호가 있는 본문, 검토·과제·질문·근거·자료 목록 부록.
- 맑은 고딕, 자동 줄 높이, 일관된 여백, 제목과 다음 문단 연결, 전체 쪽수 표시.
- 긴 제목용 표지 간격, 긴 본문·인용의 문단 분리. 문장·수치·출처는 유지한다.
- 짧은 과제는 검토 메모 열이 있는 표로 표시하고 표 머리글을 반복한다. 긴 과제는 문단으로 표시한다.
- 본문에는 근거 번호를 표시하고 원래 인용·출처 ID·위치는 부록에 보존한다. 검토 상태·확인 필요 표시와 원래 시각도 유지한다.
- 입력 문자열이 Word 명령이나 외부 관계가 되지 않으며, 다운로드는 저장·AI 호출을 수행하지 않는다.

## 검증

관련 DOCX/Markdown 테스트 총 10개, lint, typecheck 통과. 격리 Webpack `build:local` r12TFt 성공: BUILD_ID `qI3eVNbIxfHj5RkrDR_AW`. 변경한 소스·시험 두 파일의 빌드 사본 SHA 일치, `.env.local` 미복사 확인.

첨부 문서의 내용을 사용한 임시 출력 34쪽과 긴 표지·40개 과제를 포함한 합성 출력 8쪽을 별도 숨김 Word 인스턴스로 PDF 렌더링하고 전체 페이지를 육안 확인했다. 표준 렌더러는 로컬 LibreOffice가 없어 Word로 대체했다. 페이지·여백 밖 글자 없음, 첨부에서 추출한 의미 필드 275개 보존을 확인했다. 이는 출력 레이아웃 검증이며 사업 내용의 사실 확인이나 대표의 인수 승인이 아니다. 고객 문서·임시 렌더링 파일은 Git에 포함하지 않는다.

## 사용 및 인계

앱에서 저장된 원고를 선택하고 Word 내려받기를 다시 누르면 새 서식이 적용된다. AI 재작성은 필요 없다. 기존에 내려받은 파일은 자동 변경되지 않는다. 원격 배포·서버 재시작·운영 DB 수정은 수행하지 않았다. 다른 진행 작업의 변경 파일은 별도로 보존했다.
