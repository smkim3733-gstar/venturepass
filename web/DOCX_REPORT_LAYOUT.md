# Word 내려받기 보고서 서식 — 2026-10-04

## 적용 범위

사용자 요청은 개별 첨부파일의 재편집이 아니라 앱의 Word 내려받기 출력 개선이다. 기존 `format=docx` 다운로드 경로가 선택한 저장 원고를 보고서로 출력하도록 `studio-export-docx.ts`만 변경했다. 다운로드 버튼, 원고 저장, AI 생성, Markdown 출력, 운영 자료는 변경하지 않았다.

- A4 표지, 내부 이동 목차, 번호가 있는 본문, 검토·과제·질문·근거·자료 목록 부록.
- 맑은 고딕, 자동 줄 높이, 일관된 여백, 제목과 다음 문단 연결, 전체 쪽수 표시.
- 긴 제목용 표지 간격, 긴 본문·인용의 문단 분리. 문장·수치·출처는 유지한다.
- 짧은 과제는 검토 메모 열이 있는 표로 표시하고 표 머리글을 반복한다. 긴 과제는 문단으로 표시한다.
- 본문에는 근거 번호를 표시하고 원래 인용·출처 ID·위치는 부록에 보존한다. 검토 상태·확인 필요 표시와 원래 시각도 유지한다.
- 입력 문자열이 Word 명령이나 외부 관계가 되지 않으며, 다운로드는 저장·AI 호출을 수행하지 않는다.

## 사용 및 인계

앱에서 저장된 원고를 선택하고 Word 내려받기를 다시 누르면 새 서식이 적용된다. AI 재작성은 필요 없다. 기존에 내려받은 파일은 자동 변경되지 않는다. 원격 배포·서버 재시작·운영 DB 수정은 수행하지 않았다. 다른 진행 작업의 변경 파일은 별도로 보존했다.
## 공통 부록 1 개선

후속 사용자 요청에 따라 모든 회사와 저장 버전의 Word 내려받기에 부록 1 제목 `대표·담당자 확인사항`을 공통 적용했다. 원래 검토 데이터는 변경하지 않고 `해당 본문 → 확인할 내용 → 확인 이유·원래 검토 의견 → 확인할 자료` 순서로 출력한다. 개별 의견은 우선 확인/확인 필요/참고 순이며 원래 의견 번호와 오류/주의/안내 분류도 보존한다.

같은 confirmation 의견은 문구·조치·중요도·자료 연결이 모두 같은 경우만 묶고 모든 대상 본문과 원래 번호를 남긴다. 그 외 의견은 내용이 같아도 각각 보존한다. 수치 대조 경고가 수치 오류 확정이 아니라는 설명을 붙였다. 검토 의견의 자료 연결과 본문에서 참고한 근거를 구분하며, 미지정·삭제 자료나 찾을 수 없는 과거 항목은 추측하지 않는다. 원래 message/action은 그대로 출력하고 새 사실 판단이나 자료 존재를 만들어내지 않는다.

관련 회귀 16개(신규 6개 포함), 최종 lint/typecheck/격리 Webpack Kuy9jl 통과. BUILD_ID `G8085PufzoN_5-tDMFhSY`, 변경 앱 2파일 SHA 일치 및 `.env.local` 미복사 확인. 첫 신규 시험 1개는 범위 안내 제목 대신 앞부분의 건수 요약을 찾은 문제를 제목 전체 대조로 고쳐 통과했다. 검사 조건 완화나 반복 합산은 없다.
